FAQ

Questions and things that go wrong

Common questions, and the fixes for the problems that actually come up.

General

Does this connect to my bank?

No. It never asks for net banking credentials and makes no connection to any bank. You export a statement file yourself and give it to the app — the same file your bank already emails or lets you download.

Is any of my data uploaded anywhere?

No. The application, the database and your statement files all live on your own machine. There is no account server, no telemetry and no sync. Unplugging the network changes nothing about how it works.

Which banks are supported?

HDFC, HDFC Credit Card and IOB, in .txt, .csv and .pdf depending on the bank. The Upload page shows which formats apply to the account you have selected.

Can I use it for a bank that is not listed?

Not without code changes. Support for a bank is a parser matched to that bank's export format; adding one means implementing a single interface and registering it. The source is on GitHub if you want to add your own.

Does it cost anything, and does it expire?

No. There is no subscription and no licence check. An installed copy keeps working whether or not anything new is ever released.

Installing and running

Windows says the publisher is unrecognised

The build is not code-signed, so SmartScreen warns on first run. Choose "More info", then "Run anyway". If you would rather verify it yourself, build it from source — the repository has the full build script.

Something else is already using port 5080

The app serves on localhost:5080. If another program has that port the service will start and then stop. Free the port, or change the Urls setting in appsettings.json next to the installed executable and restart the service.

The service will not start

Check the log files in the Logs folder next to the installed executable, and pgsql.log inside the Data folder. The usual causes are a port conflict and the Data folder not being writable by the LocalService account, which the installer normally grants.

Do I need to install PostgreSQL or .NET?

Neither. PostgreSQL 18 is bundled and runs embedded, and the .NET runtime is compiled into the executable. The installer is the only thing you need.

Can I run it on macOS or Linux?

Not from the installer, which is Windows-only. The application itself is ASP.NET Core and the source builds elsewhere, but the bundled database binaries are Windows builds, so you would point it at your own PostgreSQL.

Statements and parsing

My statement PDF has a password

That is fine — you are prompted for it on upload. To let unattended imports open protected files, save the password against the account under Settings → Accounts.

I uploaded the same statement twice

Nothing breaks. Transactions are matched on the bank's own reference, so an overlapping date range adds only what is genuinely new.

An import went wrong — how do I undo it?

Upload History has a Revert action against every import. It removes that import's transactions and the stored file together, leaving everything else untouched.

A statement imported but the transactions look wrong

Revert the import first so you are not working around bad rows. If the file is a format the parser has not seen, open an issue on GitHub with a description of the layout — do not attach a real statement, since it contains your account details.

Why is my income so much higher than I expected?

Most often because money moved between your own accounts is being counted twice — once as spend leaving one account, once as income arriving in another. Open Transfers and confirm the suggested pairs; that takes both sides out of the totals.

Data and privacy

Where exactly is my data stored?

In a Data folder beside the installed executable: the embedded PostgreSQL database, your uploaded statement files, and the key used to encrypt the login cookie.

How do I back it up?

Stop the service, copy the Data folder, start the service again. Restoring is the same steps in reverse. Restore onto the same version or a newer one.

Can I hide the amounts when someone is looking?

Yes — the eye button in the header masks every amount on screen, and counterparty names as well if you turn that on.

Can more than one person use it?

Yes. Additional users can be created under Settings → Profile, each with their own login.
