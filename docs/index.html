Install

Download the installer from the releases page and run it. It installs machine-wide under Program Files, so Windows will ask for administrator rights.

  1. Run the downloaded setup file.
  2. Windows SmartScreen may warn that the publisher is unrecognised — the build is not code-signed. Choose "More info", then "Run anyway".
  3. Accept the install location, or change it.
  4. Setup registers a background service and finishes.

A desktop shortcut is created. It opens your browser at the address the service listens on rather than launching an executable, because the app is a local web application.

Where it runs

http://localhost:5080 — the shortcut, the Start menu entry and any bookmark all point here.

Portable instead

The portable build is the same application without the installer. Unzip it and run the executable directly. Nothing is written outside the folder you extracted it to, no service is registered, and the app runs only while the window is open.

First run

The first time you open the app it asks you to create an administrator account. That username and password are stored locally — there is no sign-up, no email verification and no remote account.

A short guide opens automatically on first login. You can reopen it any time from the ? button in the page header.

Forgot the password?

There is no reset email — nothing leaves the machine. Additional users can be created under Settings → Profile while you are signed in, so add a second admin if you want a way back in.

Add an account

Everything starts with an account — one for each bank account or credit card you want to track. Use the "+ Add" button in the account filter, or Settings → Accounts.

Supported banks are HDFC, HDFC Credit Card and IOB. Credit cards additionally take a credit limit and a statement day, which drive the utilisation meter and the billing-cycle view.

Export a statement from your bank

The app reads the files your bank already provides. It never asks for your net banking credentials and never connects to your bank.

HDFC Bank — .txt or .pdf

  1. Log in to HDFC NetBanking.
  2. Go to Accounts → Enquire → Statement of Account (or "Download Historical Transactions").
  3. Pick the account and the date range you want.
  4. Choose the "Delimited (.txt)" file type and download.
  5. Or upload the monthly e-statement PDF emailed by the bank — enter its PDF password if it is protected.

HDFC Credit Card — .csv or .pdf

  1. Log in to HDFC NetBanking.
  2. Go to Cards → Credit Cards → View / Download Statement.
  3. Select the card and billing period.
  4. Download the statement in CSV format.
  5. Or upload the monthly e-statement PDF emailed by the bank — enter its PDF password if it is protected.

Indian Overseas Bank — .txt or .pdf

  1. Log in to IOB NetBanking.
  2. Go to Account Statement / Statement of Account.
  3. Select the account and the period you want.
  4. Download / export the statement as a text (.txt) file.
  5. Or upload the e-statement PDF — enter its PDF password if it is protected.

Upload it

Open the Upload page, pick the account, and drop the file in. The page shows which formats the selected bank accepts, and links to the same export steps listed above.

  • Password-protected PDFs work — you are prompted for the password.
  • Duplicates are skipped automatically, so re-uploading an overlapping date range is safe.
  • Every import is listed in Upload History with the number of transactions it added.
  • Revert removes that import completely — its transactions and the stored file.

Import without lifting a finger

Under Settings → Accounts, each account can watch a folder. Point it at wherever your browser saves statements and new files are imported on their own.

  • The folder is swept about once a minute, so a file dropped while the machine was off is still picked up on the next start.
  • Files already imported, recognised as duplicates or failed are remembered and not retried, unless you edit the file or restart the service.
  • A statement password can be saved per account so protected PDFs import unattended.
  • "Import now" runs a sweep immediately instead of waiting for the interval.
  • Anything that fails is reported in the notification bell in the header.

Review and categorize

Imported transactions are categorized automatically by merchant. The counterparty is resolved out of the raw UPI string or narration, and each merchant carries a default category.

  • Transactions — filter by date, re-categorize, add tags and notes.
  • Merchants — rename, merge duplicates, bulk-categorize, set default categories.
  • A category set on a single transaction always wins over the merchant default.

Transfers

When a debit in one of your accounts matches an equal credit in another within a few days, the app proposes it as a transfer. Confirming the pair removes both sides from income and spending — you moved your own money, you did not earn or spend it. This is what keeps the totals meaningful once you hold more than one account.

Budgets, bills and deposits

  • Budgets — a monthly limit per category. Set once, applied to every month, measured against real spend in whichever month you select.
  • Bills — recurring bills with due dates and reminders, including credit-card bills. Opt in to desktop notifications under Settings → Reminders.
  • Investments — recurring and fixed deposits picked out of the statement narration, with contributions paid so far and maturity dates.

Reports

Reports closes off a month or a year: opening and closing balance, spend by category, top merchants, and deposits. Download PDF exports the same report as a document.

For a credit card the report is anchored to the billing cycle rather than the calendar month, because that is the period the card actually settles on.

Privacy controls

  • The eye button in the header masks every amount on screen, and counterparty names too if you want — useful when sharing a screen.
  • Appearance offers light, dark or follow-your-device, plus a text size setting.
  • Additional users can be created, each with their own login.

Where your data lives

Everything the app stores sits in a Data folder next to the installed executable — the PostgreSQL database it runs embedded, your uploaded statement files, and the encryption keys for the login cookie. Nothing is written to a cloud service and nothing is transmitted anywhere.

Backing up

  1. Stop the Bank Statement Analytics service, so the database is not mid-write.
  2. Copy the Data folder somewhere safe.
  3. Start the service again.
Restoring

Reverse it — stop the service, put the Data folder back, start the service. Restore onto the same or a newer version; older versions will not understand a newer schema.

The Windows service

The installer registers the app as a service so it is running whenever the PC is, without anyone signing in. It runs under the LocalService account rather than as an administrator — the embedded PostgreSQL refuses to run elevated, so this is deliberate.

Manage it like any other service: open services.msc and look for Bank Statement Analytics, or use sc stop / sc start from an administrator prompt.

Uninstall

Uninstall from Settings → Apps → Installed apps, as usual. The uninstaller stops and removes the service first.

Your data

Check whether the Data folder survived the uninstall before you reinstall or delete the install directory — it holds your entire transaction history.
